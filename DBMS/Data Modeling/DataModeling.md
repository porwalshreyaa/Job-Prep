    Data Modeling: Creating structured representations aka models of the data to define how one element relates to another.

## Types of Data models

1. Conceptual Data Model (understanding of relationships before designing the database)
2. Logical Data Model (outlining the scheme, relationships and rules)
3. Physical Data Model (creating database schema and enforcing relationships and contraints on database)

## Data Modeling Process

1. Identifying data sources
2. Defining Entities and Attributes
3. Mapping Relationships
4. Choosing a model Type
5. Implementing and Maintaining

## Types of Data Modeling

1. Hierarchical Model
2. Relational Model
3. Object-Oriented Data Model
4. Network Model
5. ER-Model
